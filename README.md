# Insurance Data Preprocessing & Exploratory Analysis

A Python-based data preprocessing and exploratory analysis project using an insurance dataset.

## Project Overview

This project focuses on preparing, cleaning, and exploring insurance data using Python. The analysis covers data inspection, handling duplicated records, checking missing values, converting data types, and exploring relationships between different variables through visualizations.

The project was developed using Jupyter Notebook and focuses on practical data preprocessing and exploratory data analysis techniques.

## Dataset

The project uses an insurance dataset stored in:

`insurance.csv`

The dataset contains information related to insurance customers, including demographic and insurance-related variables.

## Objectives

The main objectives of this project are to:

* Inspect and understand the dataset.
* Identify missing values and duplicated records.
* Examine data types and unique values.
* Convert appropriate columns to categorical data.
* Explore numerical and categorical variables.
* Visualize distributions and relationships between variables.
* Prepare the data for further analysis or machine learning tasks.

## Data Preprocessing

The preprocessing stage includes:

* Loading the dataset from a CSV file.
* Inspecting the dataset structure and dimensions.
* Checking data types.
* Checking for missing values.
* Checking for duplicated rows.
* Exploring unique values in categorical columns.
* Converting appropriate variables to categorical data types.
* Preparing the dataset for further analysis.

## Exploratory Data Analysis

Several visualizations were used to understand the dataset and identify patterns.

### Distribution Analysis

The project explores the distribution of numerical variables using:

* Histograms
* KDE plots
* Box plots

These visualizations help identify the distribution, spread, and potential outliers in the data.

### Categorical Analysis

Categorical variables were explored using:

* Count plots
* Pie charts

This helps understand the frequency and distribution of different categories.

### Relationship Analysis

Relationships between variables were explored using:

* Scatter plots
* Pair plots
* Bar plots
* Line plots
* Correlation heatmaps

These visualizations provide a better understanding of relationships and patterns within the dataset.
